# requirements.txt — PiBot-Dora
#
# The pip-installed dependencies, pinned to what is actually in the venv
# (Python 3.14.4, rebuilt 2026-08-17). Every package listed here is imported by
# code in nodes/ or src/ and resolves to the venv's site-packages.
#
# The venv is created with --system-site-packages, so a second set of
# dependencies is supplied by the OS (apt) and is deliberately NOT listed here.
# Pinning them would fight the system packages they shadow. What the code
# imports from the system, and what provides it:
#
#     numpy       python3-numpy        (IK / gait math, IMU filters)
#     pyaudio     python3-pyaudio      (mic + speaker, audio node)
#     lgpio       python3-lgpio        (GPIO on the Pi 5 — the only GPIO lib we use)
#     spidev      python3-spidev       (SPI for the WS2812B LEDs)
#     smbus       python3-smbus        (legacy I2C helper pulled in by src/)
#     yaml        python3-yaml         (config/config.yaml loader)
#     libcamera   python3-libcamera    (camera node)
#     picamera2   python3-picamera2    (camera node)
#
# To rebuild: python3 -m venv --system-site-packages venv && \
#             venv/bin/pip install -r requirements.txt
